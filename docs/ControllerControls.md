# コントローラ操作

XInput対応パッド1台を使用する。スターフォックス64を参考にした操作で、ボム・特殊攻撃は追加していない。

| 操作 | Xbox表記 |
| --- | --- |
| 操縦・照準 | 左スティック |
| 射撃 | A または RT |
| ブースト | X 長押し |
| ブレーキ | Y 長押し（ブーストより優先） |
| 左右の傾き | LB / RB 長押し |
| バレルロール | 同じ LB / RB を0.25秒以内に2回押す |
| 前 / 次の武器 | 十字キー左 / 右 |
| ポーズ・再開 | Start |
| 決定 / 戻る | A / B |
| タイトルで設定を開く | Y |

スティックを離すと照準はゆっくり中央に戻る（中心からのずれが約0.9秒で半分になる）。初期状態は通常操作（上に倒すと上昇）。タイトル設定でAまたは十字キー左右、ポーズの「設定」→「PAD PITCH」でAを押すと上下反転を切り替えられる。設定はアプリ実行中のみ保持する。

ポーズの「設定」→「PAD AIM」で照準感度を50〜200%まで10%刻みで変更できる。十字キー左右で調整し、100%が従来の照準速度（基準速度1.8）に相当する。感度は照準の移動速度にだけ掛かり、中央へ戻る速度には影響しない。リトライやステージ変更でもアプリ実行中は保持する。キーボードではSで設定を開き、上下で項目選択、左右で感度調整、Enterで決定、Escで戻る。マウスでは設定をクリックして「−」「＋」で調整できる。

左スティックの倒し具合で照準の移動速度を決める。中央付近はゆっくり動き、倒したままなら端付近でも減速しない。照準画像がはみ出さない画面端（照準中心は端から64px）までを移動可能領域とし、下記の機体との距離制限も適用する。操作中は中央へ引き戻さず、離したときだけゆっくり戻す。照準の移動・復帰は経過時間で計算する。

パッドの機体操舵は、機体から照準への方向を使い、距離上限で最大の操舵入力となる。通常ステージ・全方向飛行とも操舵入力の追加補間を行わず即時反応する。照準の移動速度と機体の追従は別の設定で、パッド操舵はマウス感度の設定から独立している。EX-ZODIACのアナログ操作を参考に反応の遅れを減らす方向で調整しており、同作の内部係数を再現したものではない。

参考：[EX-ZODIAC公式ストアの操作説明](https://store.steampowered.com/app/1249480/ExZodiac/)。アナログのXInput対応コントローラを推奨している。

パッド操作時は、機体の画面上の中心から照準中心までの距離を、画面短辺の30%以内（1280×720では216px）に制限する。上下左右・斜めとも同じ距離で制限し、機体の移動とカメラの更新後にも補正する。上限に達しても入力を蓄積しないため、逆方向へ操作するとすぐ動く。機体が画面外にある場合は、照準画像が収まる画面端を基準にする。機体がカメラの背後にあるときは距離補正を行わない。

通常弾・ミニガンは長押し連射、ミサイルは押下時、ホーミングミサイルは長押しでロックして離すと発射する。AとRTの同時押しも1つの射撃操作として扱う。

ロールは0.5秒で1回転し、再使用まで1秒待つ。ロール自体に無敵・弾の反射は付けていない。

ポーズ中は十字キー上下で「再開 / リトライ / 設定 / タイトル」を選択し、Aで決定する。設定では「照準感度 / 上下反転 / マウス感度 / 戻る」を選ぶ。Bは設定からポーズに戻り、ポーズ画面では再開する。Startでも再開できる。ゲームオーバーではAでリトライ、Bでタイトルへ戻る。クリアではAまたはBでタイトルへ戻る。

キーボード・マウスの操作も利用でき、使用した入力に応じて照準方式とガイド表示を切り替える。コントローラ操作中にパッドが切断されるとポーズする。接続直後に押されているボタンは、一度離すまで受け付けない。ステージ開始・ポーズ解除後は射撃ボタンを一度離すまで発射しない。

## 実機での確認項目

- タイトル → チュートリアル → STAGE 1 → ポーズ → リトライ / タイトルをパッドだけで操作できる。
- レール飛行・全方向飛行の両方で操縦でき、上下反転が照準と機体の両方に反映される。
- 通常弾 / ミサイル / ホーミング / ミニガンの射撃と武器変更が正しく動く。
- XとYの同時押しではブレーキが優先される。
- LB / RBの長押しでは傾き、2回押しでは左右のロールになる。
- パッド切断でポーズし、再接続時・再開時に誤射しない。
- マウス操作へ戻した後、パッド操作へ再度切り替えられる。
- 機体との距離が短辺の30%以内に収まり、上限で倒し続けた後もすぐ逆方向へ動かせる。
- 画面の端でスティックを離すと、照準の中央復帰に機体も追従できる。
