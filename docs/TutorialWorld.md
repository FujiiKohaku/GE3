# チュートリアルのデータ空間

タイトルのゲーム開始（Space / Enter / パッドA）から自動的にチュートリアルへ進む。タイトルのUIが消え、約1.4秒でカメラが機体へ寄る。機体のシアン色の変化とスキャン線、暗転で訓練システムへの接続を表現する。ロード中は「SIMULATION INITIALIZING」を継続表示する。

チュートリアルに入ると、約1.5秒で手前から奥へデータ世界が構築され、カメラがプレイ位置へ移動する。この間は飛行と射撃を停止し、SKIPは利用できる。構築後に「TRAINING START」を表示して操作を開始する。演出時間は合計約2.9秒で、ロード時間は別途必要。

原点からZ方向へ3,600の直線レールを進み、青いグリッド床、データ柱、六角形の練習リング、終点の緑色の出撃ゲートを配置している。背景は暗い紺色で、距離のある構造物は同色の霧に溶け込み、リングと柱の輪郭にはブルームを適用する。装飾には当たり判定を付けていない。

飛行中にパッドのBack / Viewボタン、またはキーボードのEnterを押すとSKIPし、STAGE 1へ進む。ポーズ中のEnterはメニュー決定として扱う。全訓練の達成後、機体の150先に緑色の出撃ゲートを開き、到達すると同じ遷移を行う。0.45秒のフェード後、既存のロード画面を経由してSTAGE 1を開始する。遷移時には射撃入力を一度離すまで発射をブロックする。

画面下中央に専用クラス `TutorialCommPanel` の通信パネルを配置する。背景・角を切った枠・区切り線・7本の動く音声波形・進行目盛りはwhite.pngのSprite、文字は既存のTextで描画する。1280×720では横720×縦144、画面下から44の位置を基準に、ウィンドウサイズに合わせて調整する。表示時に短いフェードとスライドを入れる。

`TutorialController` が以下の8課題を順に判定する。通信パネルには各課題の説明・必要な操作・達成数を表示し、達成後は確認音と1.1秒の確認メッセージを挟む。説明開始から4秒後には一行の操作ガイドへ縮小する。上下反転が有効な場合は移動課題の操作ガイドに表示する。

| 課題 | 操作と達成条件 |
| --- | --- |
| 移動 | 左スティックの左右上下をそれぞれ0.15秒以上操作 |
| 射撃 | A / RTで実際に3発発射（弾の生成数で判定） |
| ブースト | Xで実際に0.6秒間連続ブースト |
| ブレーキ | Yで実際に0.6秒間連続減速。X同時押し時もブレーキ優先 |
| 傾き | LBとRBをそれぞれ0.35秒以上操作 |
| ロール | 同じLB / RBを0.25秒以内に2回押し、実際にロール開始 |
| 武器 | 十字キー左右で課題開始時から武器が変わる |
| ポーズ | 手動でSTARTポーズを開き、訓練に戻る。設定から感度調整できることも案内 |

未達成の課題ごとに前進距離を制限し、練習中にコース終端へ流されないようにする。ポーズ・デバッグカメラ操作・時間停止中は達成判定を進めない。パッド切断による自動ポーズはポーズ課題の達成に含めない。マウス・キーボードでも移動、射撃、速度操作、武器切替、ポーズの代替案内を表示するが、傾きとロールは現在のパッド操作を使用する。ボム・特殊攻撃は課題に含めない。

構築演出・ポーズ・出撃中はパネルを表示しない。SKIP表示はパネルと重ならない右下に置く。`ShowMessage`、`SetCompact`、`SetProgress`、`Hide`で呼び出し側から表示を制御できる。

- コース設定：`project/resources/Stages/Tutorial/settings.json`
- 配置：`project/resources/Stages/Tutorial/layout.json`
- 色・霧・ポストエフェクト：`project/resources/Graphics/visual-presets.json` と `GamePlayScene.cpp`
- 形状の生成：`tools/generate_tutorial_world.py`（Pythonで実行するとOBJと配置を再生成する）

静的な装飾は5つのメッシュにまとめている。生成に乱数を使う配置は固定シードで再現する。
