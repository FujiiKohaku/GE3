# 加速時の火花ポストエフェクト

`BoostSparks.PS.hlsl`で白〜オレンジの細い火花を生成する。
画面中心付近は薄くし、加速エフェクトの中心から外側へ流れる。
火花ごとに発生位置・寿命・長さを変え、42Hzのランダムな明滅でチリチリした印象を作る。

## 組み込み

- GamePlaySceneの既存ブースト判定に連動する。
- 加速開始のキック強度に合わせて火花を強める。
- 時間ベースの平滑化で表示・消去する。解除後は約0.4秒で消える。
- 強度が0になるとポストエフェクトチェーンから外れる。
- シーン終了時には強度と経過時間をリセットする。
- 既存ブラーの後、Bloomと最終色変換の前に合成する。
- 既存定数バッファの8バイトのパディングを強度と経過秒数に使い、他の項目のオフセットを維持する。

## 実行コスト

表示中に全画面描画1回、入力画像のサンプル1回/ピクセルを追加する。
火花の計算はピクセル周辺の3方向に限定する。中心では早期終了する。
GPU負荷は解像度に比例する。実機でのGPU時間とゲーム内の見た目は未計測。

## 調整箇所

- 密度：シェーダーのkSectorCountとisVisibleの閾値。
- 長さ・太さ・色：trailLength、halfWidth、tint。
- 明滅速度：42Hzの値。
- 中心の保護範囲：centerMaskのsmoothstep。
- 解除時の余韻：GamePlaySceneのkSparkFadeRate。
