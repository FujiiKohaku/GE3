# App のフレーム依存処理の確認・修正

2026-10-21。調査開始時の `project/App` 全136ファイル（C++実装63ファイルとヘッダー）を対象に、固定時間、フレームカウンター、毎更新の加算、追従補間、射撃周期を確認した。

## 修正内容

| 対象 | 変更 |
| --- | --- |
| NormalEnemy / PaintShooterEnemy / MoveEnemy | フレーム数による射撃待機を経過秒に変更。周期の端数を維持し、長時間停止後の連射は1更新3回までに制限 |
| SwarmEnemy | 射撃周期の端数を維持。停止中には発射しない。既存の1更新1回の上限を維持 |
| SwarmPulseBullet | 移動・波形・回転を経過秒で進める |
| HomingMissileBullet | 追尾補間率を経過秒に応じて変換 |
| Player | レール内の入力移動・エリアから受ける押し戻しを経過秒で積算 |
| GamePlayScene | 死亡時・通常時のカメラ追従、FOV、HP表示、ブースト演出中心の追従率を時間換算。カメラポイントは固定した開始位置から補間 |
| GamePlayScene | 回復アイテムの浮遊・回転を時間換算 |
| TestScene1 | 固定1/60秒によるタイマー・アニメーション、移動・旋回・ジャンプ・接地補正・足IK・回復アイテムを時間換算 |

共通の `GameTiming` に60FPS基準値の時間換算、指数補間、周期の端数管理を集約した。既存の `FearWormTiming` はこの共通実装の別名として使用する。

通常敵JSONの `fireIntervalFrames`・`bulletSpeedPerFrame` など、既存データの形式は維持する。フレーム表記の設定は60FPSを基準に内部で時間換算するため、設定ファイルの移行は不要。

コンパイル確認中に見つかった開発パネルのカメラ操作は、constなgetterの戻り値への代入をsetter呼び出しに修正した。

## そのまま維持した値

- 敵・弾・描画・配列・ループの個数や添字。FPS計測とフレーム表示のためのカウンター。
- 既に `GetDeltaTime()` で積算する処理。
- ポーズ中にも動かすUI・チュートリアル・カットインの `GetUnscaledDeltaTime()`。
- ボーンなどの空間的なブレンド率。時間経過による追従とは区別する。
- 速度の60FPS基準値と、同じ単位で求める予測距離。実際の移動では経過秒を掛ける。

## 実行コスト

加算・乗算と、追従箇所の `pow` 計算が増える。時間換算自体はメモリ確保を行わない。射撃の追いつき処理には上限を設ける。実測の性能ベンチマークは実施していない。
