# 道中エネミー：氷と未知の物質（試作）

リファレンスの核・黒い組織・氷の結晶を、ゲーム用の少ない面数で試作したモデル。
アニメーション、UV展開、テクスチャ制作、ゲーム内マテリアル設定は未実施。
ゲームコードと既存モデルは変更していない。

- EnemyModels.blend：5種類を並べた編集用シーン。
- 各敵の.glb：原点付近のモデルとPBRマテリアル。カメラと照明は含まない。
- 各敵の.obj / .mtl：OBJ互換出力。GLBと同じ透過・発光表現を再現できる形式ではない。
- preview.png：Blender Cyclesでレンダリングしたプレビュー。ゲーム内の表示とは異なる。
- create_models.py：モデルとプレビューの生成スクリプト。

| モデル | 三角形数 | 材質別プリミティブ数 |
|---|---:|---:|
| NormalEnemy | 800 | 3 |
| MoveEnemy | 1030 | 3 |
| ArmoredEnemy | 840 | 3 |
| PaintShooterEnemy | 1142 | 4 |
| SwarmEnemy | 70 | 3 |

プレビュー上段は左から通常・移動・装甲、下段はペイント・群れ。
各モデルは1メッシュに統合済み。材質別の描画回数はゲーム側の実装によって変わる。
透明な氷や発光核の見た目には、エンジン側で対応する材質の設定が必要。
