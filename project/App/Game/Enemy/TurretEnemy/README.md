# TurretEnemy

固定式の砲台。土台・左右旋回台・上下に動く砲身の3モデルで構成する。

- 土台は配置位置に固定。
- 自機の位置へ最大90度/秒で照準を合わせる。
- 上向き60度、下向き10度まで砲身を動かす。
- 自機が進行方向の前方・射程170以内で、砲身との角度差が5度以内になると初弾を0.35秒後に撃つ。
- 砲口から砲身方向へ専用の `TurretEnemyBullet` を発射。追尾・放射弾は使わない。
- 次弾の待ち時間はレベル設定を使う（Stage1は2秒）。照準が一時的に外れても待ち時間は進み、射撃は照準が合うまで保留。射程外では初弾待ちへ戻る。
- 自機の40後方へ流れたら爆発せず削除。
- HP・発射間隔・基準弾速は既存の `normal-enemy-levels.json` の `level` 設定を参照。
- 専用弾は通常弾の見た目・判定サイズの1.5倍、基準弾速の5倍。設定定数は `TurretEnemyBullet.h`。
- 専用弾の色は紫。黒い輪郭と淡い紫の中心を使い、通常敵の赤い弾と区別する。
- 弾の背後へ最大8ユニットの紫の尾を描画。尾は見た目だけで、命中判定は先端の弾にだけある。
- 発射時は砲口に0.07秒の閃光、砲身に0.24秒の反動・復帰（最大0.7ワールドユニット）、専用の発射音を同期。
- 発射演出の定数と初弾待ちは `TurretShotFeedback.h`。演出用オブジェクトは砲台・弾の生成時に確保し、毎フレームの生成はしない。
- 表示スケールは `TurretEnemyAim::kDisplayScale`（現在3.5）。
- 3パーツそれぞれにモデルのローカル寸法から求めたOBBを持ち、旋回・上下照準に追従する。
- どのパーツに当たっても本体の共通HPへダメージ。被弾火花・撃破爆発は既存の処理を使う。

## Stage1の配置

すべてレベル2（HP4・初弾0.35秒・次弾2秒・専用弾速2.4/基準フレーム＝144/秒）。

| 奥行き | 左右位置 | 土台の高さ |
|---|---|---|
| 300 | -18 | -23.0 |
| 1450 | 19 | -23.0 |
| 3100 | -20 | -23.0 |
| 4750 | 19 | -23.0 |

各砲台の下に、幅約12・高さ22の八角形の石造台座を配置。
台座の上面は砲台の設置位置、底面は高さ-45で水面下へ伸びる。
台座は固定のステージオブジェクトで、砲台の撃破後も残る。
材質は既存の遺跡と同じ砂岩テクスチャ。箱判定を持つ。

下側分岐へ移動した場合、上下照準の制限によって上側の砲台が狙えない区間がある。

```json
{
  "name": "Enemy_Turret_Intro_Left",
  "type": "EnemySpawn",
  "file_name": "TurretEnemy",
  "level": 2,
  "transform": {
    "translation": [-18.0, 300.0, -29.5],
    "rotation": [0.0, 0.0, 0.0]
  }
}
```

JSONのtranslation順は「横・奥行き・高さ」。
モデルは `resources/Models/Enemy/Turret`。プレビュー用モデルの3パーツを個別に読み込み、色別の2×2テクスチャで配色を再現する。
