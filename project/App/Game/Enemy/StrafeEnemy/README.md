# StrafeEnemy

横から入り、レールの前方を横切りながら通常弾を撃ち、反対側へ離脱する敵。
PaceEnemyのような停止・並走区間はなく、一定の横速度で通過する。
レールの進行と曲がりに追従し、地面・水面・壁には依存しない。
自機の手動の上下左右移動には追従しない。

- 見た目は仮の黄色いCUBE（4×2.5×4）。同じ大きさ・向きの箱判定を使う。
- 待機中は非表示・当たり判定なし。
- 中盤の指定区間で設定した回数だけ射撃。標準は4秒で横断し、1・2・3秒の時点で3発。
- 射撃は通常の赤い直進弾。HPと弾速は既存の `level` 設定を使い、放射弾は撃たない。
- 横断時間が変わっても、射撃する区間の割合と弾数を維持する。
- 射程外や長いフレームで過ぎた射撃を、後からまとめて撃たない。
- 離脱・配置点の通過・レールのワープによる削除では爆発しない。撃破時は既存の爆発を使う。

## 配置

Stage1に2体配置済み。配置点840から右進入、2020から左進入。
どちらも120手前で出現開始し、レベル1（HP1）を使う。
サンプルは石壁と重ならないよう高めに配置し、横断幅も広げて画面外側から進入させている。

```json
{
  "name": "Enemy_Strafe_Right",
  "type": "EnemySpawn",
  "file_name": "StrafeEnemy",
  "level": 1,
  "strafeEnemy": {
    "entrySide": "right",
    "activationDistance": 120.0,
    "durationSeconds": 4.0,
    "forwardOffset": 90.0,
    "offsetX": 0.0,
    "offsetY": 14.0,
    "sideDistance": 140.0,
    "shotCount": 3,
    "fireStartProgress": 0.25,
    "fireEndProgress": 0.75
  },
  "transform": {
    "translation": [0.0, 840.0, 0.0],
    "rotation": [0.0, 0.0, 0.0]
  }
}
```

`translation` は出現判定用の配置点（横・奥行き・高さ）。
実際の飛行位置はレール基準で `forwardOffset`・`offsetX`・`offsetY` を指定する。
横の範囲は `offsetX ± sideDistance`。右進入では右から左へ、左進入では左から右へ動く。
射撃区間は横断全体を0〜1で表した割合。1発の場合は開始割合で撃つ。
ステージ内の壁などを避ける経路探索は行わないため、飛行位置は配置側で調整する。
