# 霧の散乱・吸収と時間蓄積

既存の半解像度のレイマーチを拡張します。高さ霧、球／箱の局所霧、太陽光と最大2灯のスポットライト、既存のシャドウマップによる光の遮蔽は引き続き利用します。森のモデルや材質の見た目を変更する処理ではありません。

## 散乱と吸収

`scatteringAlbedo` は0〜1、既定1です。既存の密度を消散係数とし、散乱係数を密度×albedo、吸収係数を密度×(1-albedo)として扱います。視線の各区間で `exp(-density * stepLength)` を乗算し、背景の透過率を求めます。albedoを変えても消散量は変えず、光の散乱と環境霧色の寄与だけを減らします。局所霧を有効にしてalbedo=0にすると、背景を暗くする吸収だけの霧になります。albedo=1は従来の強度規約です。

既存のライトのみのモードは、従来どおり背景の減衰を追加しません。位相関数の強度規約、環境色による近似、ライトからサンプル位置までの媒質内減衰は従来の近似です。多重散乱や波長ごとの吸収を計算するパストレーサーではありません。

参考：[PBRTの透過率](https://pbr-book.org/4ed/Volume_Scattering/Transmittance)、[散乱・吸収](https://www.pbr-book.org/4ed/Volume_Scattering/Volume_Scattering_Processes)。

## 時間蓄積

`shouldUseTemporalHistory` は既定true、`historyWeight` は既定0.9、範囲0〜0.95です。時間蓄積ONでは、画素ごとのハッシュとフレームごとのオフセットでレイマーチのサンプル位置を区間内でずらします。OFFでは従来の区間中央のサンプル位置を使います。サンプル本数は変えません。

計算後に半解像度の履歴パスを1回描きます。現在の深度から視線の終点を復元し、前カメラ相対座標と前の投影行列で履歴へ再投影します。履歴の表面距離と予測距離が一致する4近傍だけを補間します。現在の3×3近傍のうち深度が合う画素から色と透過率の範囲を求め、古い値をその範囲へ制限してから混ぜます。距離のガイドは現在値を保持します。合成は従来の深度差を使う拡大処理です。

カメラの識別子・カットID、シーンrevision、霧と照明の設定、影の投影行列を照合します。カメラが2ワールド単位を超えて移動する場合や、向きが約11度を超えて変わる場合も履歴を破棄します。OFF、入力不足、未消費の前フレーム入力、サンプル数・履歴重み・散乱割合・時間蓄積の変更では履歴を使いません。Rendererからシーンrevisionを渡します。

視線終点による再投影は体積全体の正確な3次元再投影ではありません。動く影の形、流れるノイズ、手前の霧だけの移動では残像が出る場合があります。フロクセル格子や物体IDによる判定は未実装です。影のカメラや照明・霧の設定が毎フレーム変わる場面では、安全のため履歴を破棄する頻度が増えます。密度ノイズの流れ自体は設定ハッシュから除き、現在近傍のクランプで処理します。

## 品質と操作

`SetQuality()` のLowは16、Mediumは32、Highは64サンプルです。直接 `SetSampleCount()` で8〜64を指定するとCustomになります。既定はMediumです。距離と密度、霧の数、ノイズ、影を参照するライト数も負荷に影響します。

ImGuiのVolumetric LightとDevelopmentパネルから、品質、サンプル数、時間蓄積、履歴重み、散乱割合を変更できます。探索・時間蓄積・合成のGPU時間と画像の実割当を表示します。GPU時間は前フレームのコマンドの完了後に読みます。Releaseの通常構成では既存のGPUタイマー規約により計測を省略する場合があります。

```cpp
auto* volume = postEffects->GetVolumetricLightRenderer();
volume->SetQuality(VolumetricQuality::Medium);
volume->SetTemporalEnabled(true);
volume->SetHistoryWeight(0.9f);
volume->SetScatteringAlbedo(0.9f);
```

## 実行コスト

光線のサンプル数や影パスは増えません。時間蓄積が必要になったときに初めて、半解像度RGBA16_FLOATの散乱＋距離とR16_FLOATの透過率を2組、計4枚確保します。1280×720では画素データ約4.39MiB、検証GPUでの実割当は4.75MiBでした。元の2枚の実割当2.375MiBを含む合計は7.125MiBです。OFF後も再利用用に確保済み画像を保持します。

時間蓄積の追加描画は640×360で1回です。4個の全解像度深度、現在値、履歴4近傍、現在3×3近傍の参照と再投影・クランプを行います。SRVを4つ、RTVを4つ追加します。GPU定数を96bytes拡張しますが、アップロード領域は従来と同じ1024bytesに収まります。CPUではカメラと最大8霧／2スポットの設定をハッシュ照合します。

時間蓄積OFFでは追加画像を初回確保せず、履歴描画とジッターを省きます。霧全体OFFや入力不足では探索・蓄積・合成を省き、計測値を0へ戻します。相対的な追加msは通常実行の管理した条件で測定していません。

## GPU検証

`DxrTests.exe --volumetric` は一様霧の透過率をBeerの式と比較します。albedo=0・0.5・1による吸収と散乱、低／中／高品質、薄い球状の霧の8サンプルを32フレーム蓄積した誤差、透過率の0〜1範囲、手前の深度の出現、カット・小さなカメラ移動・シーン／密度変更、無効入力、OFF、GPUタイマーを確認します。引数なしの全DXR検証にも含みます。

`ShadowMapTests.exe --volumetric` は既存の霧・太陽光・スポット影の検証へ進む入口です。前段の材質・HDR・半球色・ブルーム画像比較を省きます。既存の静止画像一致は時間蓄積OFFで行い、球／箱／高さ、カメラ精度、影のON/OFF、欠けた影入力、設定リセット、静止ノイズなどを検証します。通常の全ShadowMap検証では前段も引き続き行います。

結果とPNGはruntime/captures/DxrTests/volumetric-quality-result.txtと同ディレクトリ、影との連動の結果はruntime/captures/ShadowMapTestsです。新規検証はD3D12のERROR/CORRUPTIONを失敗扱い、既存ShadowMap検証は警告も確認します。

2026-10-09、RTX 4060 Laptop GPUで新規の霧GPU検証、全DXR GPU検証、ShadowMapTestsの霧選択検証が終了コード0で成功しました。Developmentビルドも成功しています。一様霧の透過率はGPUで0.904785、数式で0.904837でした。8サンプルの薄い球のMSEは0.000647448から0.000028344へ約95.6%減りました。単純な検証シーンの結果です。単独実行時のDebug計測は探索約0.162ms、履歴約0.185ms、合成約0.221msでした。通常ゲームでの追加時間を保証する測定ではありません。

引数なしのShadowMap全体検証は、霧に入る前の「Hemisphere colors did not affect surface normals」で失敗しました。この比較は今回の霧選択検証では対象外で、全ShadowMap検証の成功とは扱いません。霧と影の選択検証の結果はresult.txtへ別の対象範囲として記録します。
