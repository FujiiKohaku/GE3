# RT間接光

`DxrGlobalIlluminationRenderer` は半解像度で拡散間接光を探索します。RT反射とDXRの材質参照・命中先照明・履歴・フィルター処理を共有し、画像と履歴は各パスが独立して保持します。初期状態はOFFです。

## 操作

ImGuiの `DXR Foundation` と `RT Global Illumination`、または開発Webパネルの「DXR基盤」と「RT間接光」を有効にします。サンプル数、時間蓄積、空間フィルター回数、強度、距離、最大放射輝度、命中先の太陽光遮蔽、均等なサンプル配分、探索距離の環境光への移行割合を調整できます。「間接光だけ表示」は合成する拡散間接光成分を表示します。

APIは `Renderer::GetDxrGlobalIlluminationRenderer()` の `GetSettings()` / `SetSettings()` です。インスタンスの既定は1サンプル、距離12ワールド単位、履歴重み0.9、時間蓄積ON、空間フィルター2回、最大放射輝度10です。距離はシーンのスケールに合わせて変更してください。サンプル配分のSobol系列は既定ON、距離の環境光への移行割合は既定0.2です。詳細は [GIのサンプル配分と探索範囲](RTDiffuseQuality.md) を参照してください。

設定と入力の型はRT反射と共有しています。設定は `GetSettings()` の結果を変更して渡してください。共有フィールドの `maxRoughness` はRTGIでは使いません。

## 探索と合成

対応面から法線の半球へコサイン重みの方向を選び、最大距離まで光線を飛ばします。既定では画素ごとにデジタルシフトした2次元Sobol系列を使い、時間蓄積ONではフレームをまたいで系列を進めます。命中先の照明をサンプルして平均し、合成時に受ける面の基本色とフレネル・金属度による拡散配分を掛けます。受ける面の鏡面強度や粗さでは探索を制限しません。金属面に拡散間接光を加算しません。

合成は `scene + strength * (rtDiffuse - capturedDiffuse * hitCoverage)` です。命中した割合に距離の重みを掛けて環境拡散光を置き換え、ミス分と距離フェード分は環境光へ戻します。既定では探索距離の末尾20%で滑らかに移行します。黒い命中も置き換えの対象です。直接光・環境鏡面反射は保持します。入力と配分の詳細は [照明の合成](RTLightingComposition.md) を参照してください。最大放射輝度は各サンプルの極端に明るい値を制限するため、制限に達する光源では推定が暗くなります。

RTGIの出力が有効なフレームではSSGIの探索・フィルター・合成を省略します。RTGI OFF、DXR OFF、入力不足などでRTGIが利用できない場合は、既存SSGIがユーザーの設定どおり動作します。切り替え時にはSSGI・RT反射・SSR・DLAAの関連履歴をリセットします。未対応材質の画素だけSSGIで補う方式は未実装です。

描画順は通常描画・TLAS構築 → RT太陽光シャドウ → RTGIまたはSSGI → RT反射 → 霧・SSR・DLAAです。RTGIデバッグ表示ではRT反射・SSRを合成せず、間接光成分の表示へ切り替えます。

## 対応範囲と履歴

受ける面はObject3dのStandard、ShadowStandard、Toon、ShadowToonと、ブレンドなしSkinningObject3dのStandard、Toonです。受ける面の法線マップ、基本色、金属度を使用します。材質キャプチャの深度と最終深度が一致する画素だけに合成し、未対応の手前の物体へ後ろの面の間接光を加算しません。

光を受け取る対象はDXRへ登録された剛体・GPUスキニングモデルです。命中先の基本色・UV・材質・補間法線・太陽光・環境光・局所ライト・環境マップを参照します。アルファ切り抜きはAnyHitで通過し、Unlitは基本色を返します。命中先の太陽光には追加の遮蔽光線を飛ばせます。

時間蓄積はモーション、ジッター差、前フレーム行列、深度・法線の照合と近傍クランプを使います。拡散面ではミスのゼロ寄与も蓄積します。信号のalphaは距離で重み付けした置き換え率です。空間フィルターは受ける面の深度・法線を参照し、受ける面の鏡面粗さに関係なく動作します。全解像度の合成時にも深度・法線を参照して拡大し、基本色・金属度は全解像度で適用します。

カメラカット、シーン変更、探索設定変更では全画面の履歴を破棄します。配置・材質・姿勢・照明変更は画素ごとに現在の信号と照合し、分散と蓄積回数でフィルターを調整します。追加コストと制限は [RTの履歴判定](RTHistory.md) を参照してください。同じGPUリソース内のテクスチャ内容だけを更新する場合は `ResetHistory()` を呼んでください。

## コストと検証

1280×720では探索は640×360、対応画素ごとに既定1本、設定で最大16本です。太陽光遮蔽ONでは命中先から追加の遮蔽光線を飛ばします。BLAS/TLASと材質キャプチャはRT反射・RTシャドウと共有します。

RTGI固有の探索・履歴・フィルター・合成画像に、共通の命中先・統計画像5枚を追加しています。現在の実割当は [RTの履歴判定](RTHistory.md) を参照してください。共有キャプチャが未確保なら材質キャプチャ22.5MiBと連続MRTスロット用の太陽光キャプチャ15MiBも必要です。OFF後も再利用用の画像は保持します。既存SSGI、モーション、DXR基盤、ドライバー内部メモリは別です。

GPU時間は探索・フィルター・合成を分けて表示します。CPU準備、初回パイプライン作成、共有MRT書き込み、モーション描画、BLAS/TLAS構築は含みません。

履歴処理改良前のRTX 4060 Laptop GPU、1280×720、カメラの後ろの大きな赤い平面から光を受ける小規模検証では、1サンプル、時間蓄積・空間フィルター・命中先太陽光遮蔽OFFで探索0.34ms、合成1.67msでした。既定設定や実ゲームの性能を保証する値ではありません。

有限サイズの赤い平面を使うノイズ検証では、16サンプル×8フレームの平均を参照し、1サンプルを32フレーム蓄積して空間フィルター2回を適用しました。参照値が0.03～0.9の画素の平均二乗誤差は0.0764961から0.00604737へ約92.1%減少しました。

`DxrTests.exe` はカメラの後ろの対象、拡散光と鏡面設定の独立性、受ける面の基本色・金属度、強度・デバッグ表示、距離・ミス、切り抜き、命中先の照明、放射輝度制限、履歴・ジッター・カット・材質・照明・シーン変更、ノイズ低減、実GPUスキニングとBLAS更新、未対応の手前面、入力不足、OFFを検証します。既存のDXR基盤・RTシャドウ・RT反射も同時に再検証し、D3D12検証レイヤーのERROR/CORRUPTIONは失敗扱いにします。結果は `runtime/captures/DxrTests/rtgi-result.txt`、PNGも同ディレクトリです。

## 現在の制限

1回の拡散反射を探索する初期実装です。命中先の既存環境照明も参照する近似で、環境光を含む全照明の置き換えやエネルギーを厳密に保存するパストレーシングではありません。命中先の法線・粗さ・金属度マップと照明は [RT材質](RTMaterials.md) の共通処理を使用します。多重反射、二次光線に沿った霧、透明ブレンド、独自材質の完全な再現は未対応です。[局所ライトRTシャドウ](RTLocalShadows.md) の有効な選択ライトは命中先でもRT遮蔽を計算し、ReceiveShadowを参照します。非選択ライトは命中先では影なしです。

通常描画を省いた対象も `SubmitRaytracing()` でTLASへ提出できます。参加条件と範囲は [RTシーン登録](RTSceneSubmission.md) を参照してください。半解像度・半精度ガイドと受ける面を基準にした履歴判定のため、細い形状、遠方の境界、対象の出入りでは画質調整が必要です。
