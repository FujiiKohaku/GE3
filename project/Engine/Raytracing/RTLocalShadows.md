# 局所ライトのRTシャドウ

`DxrLocalShadowRenderer` はポイント・スポットライトの影を半解像度で探索します。DXR基盤のTLAS、RT反射・RTGIの材質参照、履歴・空間フィルターを共有し、局所ライト用の画像と履歴は独立して保持します。初期状態はOFFです。

## 操作

ImGuiの `DXR Foundation` と `RT Local Shadows`、または開発Webパネルの「DXR基盤」と「局所ライトRTシャドウ」を有効にします。APIは `Renderer::GetDxrLocalShadowRenderer()` の `GetSettings()` / `SetSettings()` です。

既定は最大4灯、光源あたり4サンプル、発光面半径0.1ワールド単位、時間蓄積ON、空間フィルター2回です。発光面半径0では硬い影を1サンプルで探索します。半径はポイント・スポットで共有する設定です。光の到達距離であるPointLightの `radius` とは別です。

光源は `LightManager::SetPointLightShadowEnabled` / `SetSpotLightShadowEnabled` をONにした、活動中で強度が正のものを選択します。ポイントライトのインデックス順、続いてスポットライトのインデックス順に、設定した最大数まで選びます。上限は8灯です。非選択ライトの通常描画は既存のシャドウマップを使用します。

影を落とすモデルでは `SetCastShadow(true)`、受けるモデルでは `SetReceiveShadow(true)` が必要です。これらの既定がOFFのクラスもあるため、テストや新しいシーンでは明示してください。

## 探索と合成

通常描画で、選択した局所ライトの既存の照明成分を8番目のMRTへ保存します。元の材質描画は既存のシャドウマップを含めて継続するため、RTが使えないフレームは元の結果を保持できます。RGBは選択ライトの成分、alphaは鏡面反射の有無で、受けない面とクリア値は-1です。受ける面の法線、粗さ、鏡面強度、基本色、金属度は既存RTキャプチャから読みます。

各受ける画素で選択ライトの照明を再評価し、モデルから光源へ遮蔽光線を飛ばします。影の光線にはCastShadow用マスクを使い、AnyHitで切り抜き面を通過します。光線はサンプルした発光面までで終了するため、光源の後ろの物体を遮蔽物にしません。到達距離、スポットの円錐、クラスタのライト集合、面の向きによって寄与がない光源を省略します。

半径が正の場合は光源方向に垂直な円盤をサンプリングして可視率を平均します。照明の向き・減衰は光源中心を使うため、面光源の照明全体を積分する方式ではなく、遮蔽の柔らかさを近似する実装です。

合成は `scene - capturedSelectedLocalLight + filteredRtSelectedLocalLight` です。色の異なるライトも個別に遮蔽を計算してから照明成分を合計し、環境光・太陽光・非選択の局所ライトを暗くしません。元のシャドウマップとRTシャドウを二重に掛けません。

RT反射・RTGIの命中先照明でも、同じ選択ライトへ遮蔽光線を飛ばします。命中したモデルのReceiveShadowも参照します。非選択ライトは命中先では従来どおり影なしです。太陽光の遮蔽は既存の別設定を使います。

## 履歴とフォールバック

通常描画 → RT太陽光シャドウ → 局所ライトRTシャドウ → RTGIまたはSSGI → RT反射 → 霧・SSR・DLAAの順です。モーションとジッター差、深度・法線を参照して再投影し、近傍の値域で履歴を制限します。空間フィルターと拡大時には材質の色・金属度・粗さ・鏡面強度も照合し、異なる材質の照明を混ぜにくくします。

カメラカット、シーン、影の設定変更では全画面の履歴をリセットします。配置・材質・姿勢・照明・ライト選択の変更は画素ごとに現在の信号と照合します。分散と蓄積回数によるフィルター調整、追加コストと制限は [RTの履歴判定](RTHistory.md) を参照してください。同じテクスチャリソース内の内容だけを変更した場合は `ResetHistory()` を呼んでください。

最終深度と材質キャプチャの深度が一致しない画素、未対応材質、対応する半解像度サンプルがない細い面では元の結果を残します。OFF、非対応GPU、対象ライトなし、入力不足では探索・合成をせず入力画像を返します。RTの出力が無効なフレームは反射・RTGI側の局所ライトRT遮蔽も止めます。通常描画用と立体霧用の局所シャドウマップは引き続き描画します。

## 対応範囲と負荷

受ける面はObject3dのStandard、ShadowStandard、Toon、ShadowToonと、ブレンドなしSkinningObject3dのStandard、Toonです。遮蔽物はDXRに提出された剛体・GPUスキニング・アルファ切り抜きモデルです。透明ブレンド、独自頂点変形、独自材質の受け手は未対応です。Draw自体をカリングした物体はDXRへ登録されません。

1280×720では探索は640×360です。受ける画素ごとに、最大で対象ライト数×サンプル数の遮蔽光線を追加します。反射・RTGIでは命中先ごとに同じ上限の遮蔽光線を追加します。BLAS/TLASは共有し、局所ライトごとに別の加速構造を作りません。

固有の探索・履歴・フィルター・合成画像に、共通の命中先・統計画像5枚を追加しています。現在の実割当は [RTの履歴判定](RTHistory.md) を参照してください。局所ライト成分のキャプチャは7.5MiBです。共有RTキャプチャが未確保なら材質キャプチャ22.5MiBと太陽光スロット15MiBも必要です。通常のシャドウマップ、モーション、DXR基盤、ドライバー内部メモリは別です。画像は初回ONで確保し、OFF後も再使用のため保持します。

探索・フィルター・合成のGPU時間を個別表示します。CPU準備、初回パイプライン作成、MRTへの書き込み、モーション描画、BLAS/TLAS構築、既存シャドウマップ描画は含みません。

## 検証

`DxrTests.exe --local-shadows` で局所ライトを単独検証し、引数なしではDXR基盤・太陽光シャドウ・反射・RTGIと合わせて検証します。ポイント・スポット、色の異なる非選択ライトの保持、実際のシャドウマップの置き換え、光源の後ろの遮蔽物、CastShadow・ReceiveShadow、切り抜き、スポット円錐、ライト数の上限、複数ライト、柔らかい影、履歴・ジッター・カット・配置・ライト移動、実GPUスキニングの遮蔽物・姿勢更新・受け手、未対応の手前面、反射・RTGIの命中先、入力不足、OFFを確認します。D3D12検証レイヤーのERROR/CORRUPTIONを失敗扱いにします。

RTX 4060 Laptop GPU、1280×720、少数の平面を使う全GPU検証では、硬い影1灯の探索約0.23ms、合成約1.92msでした。柔らかい影1サンプルの探索約0.12ms、時間蓄積・空間フィルター約1.28msでした。Debug構成でGPUベースの検証レイヤーもONにした値で、GPUキャッシュ状態や検証処理の負荷を含みます。実ゲームの性能値としては使用できません。

16サンプル×8フレームの平均を参照し、1サンプルを32フレーム蓄積して空間フィルター2回を適用した検証では、平均二乗誤差が0.0746771から0.00416893へ約94.4%減少しました。結果は `runtime/captures/DxrTests/local-shadow-result.txt`、比較PNGも同ディレクトリです。

## 現在の制限

半解像度で照明を再評価します。履歴の変化判定は少数光線の現在サンプルによる保守的な比較で、変更中の柔らかい影は蓄積の効果が下がる場合があります。細い面や材質境界では既存の影を残す場合があり、遠方の境界や物体の出入りでは調整が必要です。受ける面の基本色・金属度は既存の8ビット材質画像から再構成するため、量子化とHDR基本色の制限があります。発光面の半径は全選択ライトで共有し、反射・RTGIの命中先では時間・空間フィルターを直接掛けず、各パスの画像側でノイズを低減します。
