# RT反射

`Renderer` が所有する `DxrReflectionRenderer` は、DXR基盤のTLASを共有して半解像度で反射光線を探索します。初期状態はOFFです。

## 操作

1. ImGuiの `DXR Foundation`、または開発Webパネルの「DXR基盤」を有効にします。
2. `RT Reflections`、または「RT反射」を有効にします。
3. サンプル数、時間蓄積、空間フィルター回数、反射強度、最大距離、最大粗さを調整します。デバッグ表示は反射成分だけを表示します。

APIは `Renderer::GetDxrReflectionRenderer()` の `GetSettings()` / `SetSettings()` です。既定は4サンプル、時間蓄積ON、空間フィルター2回、最大粗さ0.85です。粗さ0.02未満の鏡面は1本の固定方向で探索します。粗い面はGGXの可視法線分布（VNDF）で方向を選び、サンプリング確率に対応した重みを使います。詳細は [粗いRT反射の推定](RTRoughReflections.md) を参照してください。

## 対応範囲と合成

反射を受ける面は通常Object3dのStandard、ShadowStandard、Toon、ShadowToonと、ブレンドなしのSkinningObject3dのStandard、Toonです。受ける面の法線マップ、粗さ、金属度、鏡面強度を参照します。アルファ切り抜きにも対応します。

反射に映る物体はDXRへ提出された剛体・GPUスキニングモデルです。`SubmitRaytracing()` を使えば画面外でDrawを省いた物体も映ります。通常描画とRTの選別は [RTシーン登録](RTSceneSubmission.md) を参照してください。

命中先では基本色テクスチャ、材質、補間法線、太陽光、環境光、ポイント・スポットライト、環境マップを参照します。Unlitは基本色を返します。命中先の太陽光には追加の遮蔽光線を飛ばせます。AnyHitでアルファ切り抜きを評価します。

通常描画の追加MRTへ反射面情報と既存の環境鏡面反射を保存します。合成式は `scene + strength * (reflection - capturedEnvironment * replacementCoverage)` です。反射の重みで求めた置き換え率で環境鏡面反射を置き換え、光線が外れた分は既存の環境反射を残します。拡散反射と直接光は保持します。保存した深度と最終深度が一致しない画素では合成しません。

RT反射はRTGI/SSGIの後、霧・SSR・DLAAの前に合成します。Rendererでは有効なRT反射フレームのSSRを省きます。同じ画素でSSRを先に使い、失敗時にRTへ切り替える方式は未実装です。

## ノイズ除去と履歴

半解像度の反射と法線・線形深度を保存し、モーションベクトルと前フレームの行列で再投影します。ジッター差を補正し、深度・法線の不一致、新しく現れた面、画面外への投影では履歴を捨てます。近傍の値域で履歴をクランプします。粗い面では光線が外れたゼロ寄与も蓄積して、命中サンプルだけを平均する明るさの偏りを防ぎます。

時間蓄積の後、深度・法線と粗さを使った3×3の空間フィルターを0～3回実行し、合成時に深度・法線を参照して拡大します。鏡面は空間フィルターを省略します。

カメラカット、シーン変更、探索設定変更では全画面の履歴をリセットします。配置・材質・姿勢・照明の変更は画素ごとに現在の信号と照合し、鏡面は反射先の位置・距離も照合します。分散と蓄積回数によるフィルター調整、追加コストと制限は [RTの履歴判定](RTHistory.md) を参照してください。同じGPUリソース内のテクスチャ内容だけを更新した場合は `ResetHistory()` を呼んでください。

DXR OFF、入力不足、無効なカメラ、空のシーンでは入力画像を返し、古い反射を合成しません。リソース・パイプライン作成に失敗した場合はログを記録してRT反射をOFFにします。

## 実行コストと検証

- 1280×720では探索は640×360です。対応画素ごとに1～16本の反射光線と、設定に応じて命中先の太陽光遮蔽光線を追加します。BLAS/TLASはDXR基盤と共有します。
- 反射・履歴・空間フィルター・合成画像に加え、命中先・統計画像5枚を確保します。追加の材質キャプチャ2枚は22.5MiB、連続MRTスロット用の太陽光キャプチャは15MiBです。既存RT機能で確保済みのキャプチャは共有します。現在の実割当と履歴処理の追加分は [RTの履歴判定](RTHistory.md) を参照してください。DXR基盤、モーション、既存後処理、ドライバー内部メモリは別です。
- 初回ONで画像とパイプラインを作成し、OFF後も再利用用の画像は保持します。MRT書き込み、モーション描画、時間蓄積1パス、既定の空間フィルター2パス、全解像度の合成が追加されます。
- GPU時間は探索・フィルター・合成を別々に表示します。CPU準備、初回作成、MRT書き込み、モーション描画、共有BLAS/TLAS構築は含みません。

履歴処理改良前のRTX 4060 Laptop GPU、1280×720の小規模な平面検証では、鏡面探索0.35ms、合成1.68ms、粗い面の1サンプル探索0.29ms、フィルター0.80msでした。現在の処理の計測は [RTの履歴判定](RTHistory.md) を参照してください。検証シーンの値であり、実ゲームでの性能保証ではありません。

粗さ0.6の面で、1サンプルを32フレーム蓄積し空間フィルター2回を適用した画像を、16サンプルの参照画像と比較しました。反射境界付近の平均二乗誤差は生の1サンプル0.0302235から0.00261122へ約91.4%減少しました。

`DxrTests.exe` は画面外の反射対象、鏡面・粗さ、環境反射の置き換え、ミス時の保持、命中先照明・太陽光遮蔽、切り抜き、時間・空間フィルター、カメラ移動・ジッター・カット、配置・材質・照明・シーン変更、実GPUスキニングとBLAS更新、未対応の手前面、入力不足、OFFを検証します。D3D12検証レイヤーのERROR/CORRUPTIONを失敗扱いにします。結果は `runtime/captures/DxrTests/reflection-result.txt`、比較PNGも同ディレクトリです。

## 現在の制限

既定は1回の反射です。[追加1回のRT反射](RTMultipleReflections.md) を有効にすると、Standardの命中先からさらに反射を追えます。反射先の法線マップ、粗さ・金属度マップ、Standard・Toonの照明を通常描画と共有します。[RT材質](RTMaterials.md) を参照してください。2回を超える反射、反射先でのRT間接光、二次光線に沿った霧、独自材質の完全な再現、透明ブレンドは未対応です。太陽光の遮蔽は硬い影で、命中先のReceiveShadowを参照します。[局所ライトRTシャドウ](RTLocalShadows.md) の有効な選択ライトは反射先でもRT遮蔽を計算します。非選択ライトは反射先では影なしです。半解像度・半精度ガイドと受ける面の履歴判定のため、細い形状・遠方の境界・反射対象の出入りでは画質調整が必要です。

RT反射とSSRの重複防止、環境反射の置き換え、拡散・鏡面の配分は [照明の合成](RTLightingComposition.md) を参照してください。
