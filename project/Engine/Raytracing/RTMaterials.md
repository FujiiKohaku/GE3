# 通常描画とRTの材質計算

Standard・Toon・ShadowToonの材質応答を通常描画とRT命中先で共有します。RT反射・RTGIの命中先でも法線マップと粗さ・金属度マップを評価し、局所ライトの照明にも反映します。

## マップの指定

Object3dとSkinningObject3dの初期化後に設定します。

```cpp
object.SetNormalMap("resources/Textures/normal.png", 0.3f, false);
object.SetSurfaceProperties(1.0f, 1.0f, 0.35f);
object.SetMetallicRoughnessMap("resources/Textures/metallic-roughness.png");
```

法線マップは既存APIを使用し、強さ・Y反転・UV変換を通常描画とRTで共通評価します。頂点の接線属性は追加せず、通常描画は画素微分、RTは現在の三角形のワールド位置・UVから接線フレームを作ります。非一様スケール、反転したUV、GPUスキニングの更新済み頂点を使用します。UVが退化してフレームを作れない場合は元の法線を保持します。RTの頂点法線は通常の頂点シェーダーと同様、各頂点を逆転置変換・正規化してから補間します。

粗さ・金属度は線形テクスチャとして読み、Gを粗さ、Bを金属度として使用します。RとAは今回使用しません。結果は `roughness = saturate(設定値 * G)`、`metallic = saturate(設定値 * B)` です。マップ値をそのまま使う場合は両設定値を1にします。既定の金属度0のままでは、マップを指定しても金属度は0です。`SetMetallicRoughnessMap("")` で無効にします。法線マップも空のパスで無効にできます。

初回の画像読み込みは既存TextureManagerを使用します。呼び出しは更新・初期化時に行い、通常のアップロード完了後に描画します。モデルファイルからの粗さ・金属度マップの自動取り込みは今回の範囲外です。

## 共有する照明

- Standardの拡散・鏡面・環境照明。直接光と局所ライトの鏡面は、通常描画と同じ `shininess > 0` の条件で評価します。
- Toonの環境光の係数、色の帯、ハイライト、直接光・局所ライト。
- ShadowToonの別の色の帯とリムを含む環境光。Object3dのシェーダー選択に対応する識別値をRT材質へ保存します。
- 従来の環境マップの係数と `roughness * 5` のMip選択。Unlitで環境マップを追加する場合もRTへ反映します。

太陽光・選択した局所ライトのRT遮蔽は、命中先のReceiveShadowを参照します。影を避ける起点のずらしには、法線マップの凹凸とは別の面法線を使用します。通常描画の材質・反射面キャプチャにも解決後の粗さ・金属度・法線を保存するため、受け手側のRT反射・RTGI・局所ライトの再評価でも値が揃います。

## レイアウトと履歴

Materialは132から144bytesへ拡張します。alphaCutoffのoffset128を維持し、材質アップロードは従来どおり1配置256bytesです。追加した末尾の識別値・マップ有効フラグ・paddingは初期化します。

ローカルルートへ `t4, space1` の法線マップと `t5, space1` の粗さ・金属度マップを追加します。ヒットレコードの空き部分に各SRVを保存し、strideは96bytesのままです。72bytes位置が法線、80bytes位置が粗さ・金属度です。マップなしでも有効な既存の白テクスチャを結び、分岐でサンプリングを省きます。低レベルのQueue・QueueDeformedは任意の `DxrMaterialTextures` を受け取り、指定のないマップを無効化します。

材質値と追加SRVを反射シーンrevisionへ含めます。マップの切り替え・強さ・UV変更は既存の画素単位の履歴判定へ反映されます。同じSRVの画像内容だけを書き換える場合は、従来どおり明示的に履歴をリセットします。

## 実行コスト

画面用の画像・レイ本数・ヒットレコード幅・配置ごとの材質アップロード枠は増えません。通常描画へSRV入力を1つ、RTローカルルートへ2つ追加します。RT命中時は各頂点の法線を変換・正規化し、法線マップ使用時は三角形の位置・UVからフレームを作ります。有効にした面では法線と粗さ・金属度それぞれ最大1回、合計最大2回のテクスチャ参照が追加されます。通常描画の法線マップ参照は既存処理です。

テクスチャ自体は既存キャッシュを共有します。新たな画像を指定すればその解像度・形式・Mipに応じたVRAMが必要です。RT用の画像複製は行いません。CPU側は各配置のSRV2つと、そのハッシュ照合を追加します。GPU時間はマップを使う面の割合と命中数に依存するため、固定の追加msにはなりません。

## 検証と制限

`DxrTests.exe --materials` は同じ面を通常描画と完全鏡面経由のRTで描いて色を比較します。Standardの鏡面有効条件、法線の強さ・Y反転・反転UV・退化UV・非一様スケール、線形G/Bチャンネルと設定値の乗算、材質キャプチャ、Toon・ShadowToon、環境照明・従来の環境マップ・Unlit、ポイント・スポット、GPUスキニングを検証します。結果と比較PNGは `runtime/captures/DxrTests/material-result.txt` と同ディレクトリです。引数なしでは全DXRテストも行い、D3D12検証レイヤーのERROR/CORRUPTIONを失敗扱いにします。

2026-10-09にRTX 4060 Laptop GPUで材質単独テストと全DXRテストが終了コード0で成功しました。Developmentのエンジンビルドも成功しています。比較するRGB各成分の許容差は0.02で、Standard・Toon・ShadowToon・環境照明・局所ライト・スキニングの各ケースが通りました。GPU検証を有効にした機能検証であり、通常実行時の性能測定ではありません。

RT反射・RT GIのマップは [RTテクスチャのMip選択](RTTextureMips.md) により光線幅に応じてフィルターします。通常描画の画素微分とは異なる近似で、完全一致は保証しません。アルファ切り抜き判定はMip0です。通常描画は裏面を除外しますが、RTは従来どおり両面に交差し、裏面の法線を進行方向へ向けて照明を計算します。独自のIce・Archive等のシェーダーの完全な再現、AO・発光・変位マップ、2回を超える反射・二次光線の霧は今回の範囲外です。Standardからの追加1回の反射は [追加1回のRT反射](RTMultipleReflections.md) を参照してください。拡散・鏡面の配分と環境光・RTGIの合成方法は [照明の合成](RTLightingComposition.md) を参照してください。
