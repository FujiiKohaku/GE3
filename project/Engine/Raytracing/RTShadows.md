# 太陽光のRTシャドウ

`Renderer` が `DxrShadowRenderer` を所有し、同じフレームで構築したDXRのTLASから太陽方向の遮蔽を計算します。RTシャドウの初期設定はOFF、8サンプル、太陽の角半径0.00465ラジアンです。柔らかい影のノイズ除去は初期設定ON、時間蓄積は最大32フレーム、空間フィルターは2回です。角半径0では1光線による硬い影となり、ノイズ除去を省略します。角半径が大きいほど、遮蔽物から離れた場所の影が広くぼけます。

## 操作

1. ImGuiの `DXR Foundation` または開発Webパネルの「DXR基盤」でDXRを有効にする。
2. ImGuiの `RT Shadows` または開発Webパネルの「RTシャドウ」で影を有効にする。
3. 通常の照明を見るときはDXR基盤の検証画像表示をOFFにする。
4. モデルの `SetCastShadow(true)` で遮蔽物にし、`SetReceiveShadow(true)` で影を受ける。

サンプル数、太陽の角半径、法線バイアス、光線バイアス、最大探索距離を調整できます。バイアスと距離の単位はエンジンのワールド単位です。不正な値・NaN・無限値はSetterで拒否します。APIは `Renderer::GetDxrShadowRenderer()` の `GetSettings()` / `SetSettings()` です。

同じパネルでノイズ除去、時間蓄積、最大履歴フレーム数（1～64）、空間フィルター回数（0～3）を調整できます。空間フィルター0回は時間蓄積だけの比較に使えます。APIで明示的に履歴を捨てる場合は `ResetHistory()` を呼びます。

「遮蔽マスクを表示」は照明合成の代わりに白＝照射、黒＝遮蔽の画像を後処理へ渡します。ノイズ除去ONでは処理後のマスクを表示します。後続の霧・色調整・AAも適用されます。`GetMaskTexture()` は光線探索直後のマスク、`GetDenoisedMaskTexture()` は処理後のマスクです。GPU検証で保存する `shadow-*-mask.png` は後処理前の生のマスクです。

## 対応範囲

受け手は不透明・アルファ切り抜きの通常Object3dのStandard、ShadowStandard、Toon、ShadowToon材質と、ブレンドなしのSkinningObject3dのStandard、Toon材質です。対象の描画だけRT用PSOへ切り替え、通常の材質設定・テクスチャ・法線マップ・局所ライトを利用します。設定は [変形モデルのRT対応](DeformedGeometry.md)、[アルファ切り抜き](AlphaMasks.md) を参照してください。独自頂点シェーダー変形、透明ブレンド、StageIceなどの独自材質は受け手として未対応です。深度を書かない透明物を通常の3D描画内で重ねる場合の合成も未対応で、背景の太陽光と透明物を正しく分離する処理が後工程で必要です。後から描く粒子とHUDにはこの影の合成を掛けません。

遮蔽物はDXR基盤に登録される不透明・アルファ切り抜きの剛体・スキニングモデルで、CastShadowが有効なものです。切り抜き面の透明な部分を通過し、奥に不透明な遮蔽物があればそこで遮光します。`SubmitRaytracing()` を使えばDrawを省いた遮蔽物も登録できます。範囲判定は [RTシーン登録](RTSceneSubmission.md) を参照してください。

今回は太陽光に対応します。局所ライトと立体霧は既存のシャドウマップを使用します。既存の太陽光シャドウマップも未対応材質と立体霧のために描画します。

## 光の合成

通常描画で太陽光の拡散反射と鏡面反射を専用の5番目のMRTへ出力します。対応材質の太陽光についてはシャドウマップの遮蔽を掛けずに描画し、後からRTの遮蔽へ置き換えます。

合成は `sceneColor - directionalLight * (1 - visibility)` です。環境光、環境反射、局所ライト、発光などを一括で暗くしません。太陽光のシャドウマップとRTシャドウを二重に掛けません。

専用MRTはRGBA32_FLOATでRGBに太陽光、alphaにその面の深度を保存します。影の光線は、保存した深度と最終シーン深度が一致する画素からだけ飛ばします。対応外の手前の物体や空に、後ろの面の太陽光が残っていても影を掛けません。

## 処理と同期

通常描画・TLAS構築 → 深度／法線／太陽光をSRVへ遷移 → 太陽方向へDispatchRays → マスクをSRVへ遷移 → 時間蓄積と空間フィルター → HDR合成 → SSGI・霧・SSR・DLAA・粒子・最終表示の順です。深度復元にはジッター込みの現在フレームのカメラ行列を使います。影は最初の遮蔽物で探索を終了し、材質のClosestHitを実行しません。

シャドウ用シェーダーテーブルはTLASのインスタンス別HitGroupオフセットをカバーします。硬い影は1光線、柔らかい影は太陽の円盤を複数方向へサンプリングして平均します。時間蓄積ONでは円盤内の半径と回転をフレームごとに変え、過去のサンプルと合わせて平均します。時間蓄積OFFでは画素ごとの固定パターンを使用します。

## ノイズ除去

`ShadowDenoiser` は可視率と蓄積フレーム数、法線と線形深度の履歴を交互に更新します。前フレームのカメラ行列とモーションベクトルを使って再投影し、ジッター差を補正します。履歴の深度・法線が一致しない場所、画面外、新しく現れた面では現在のサンプルから再開します。モーション入力がない場合はワールド位置から前フレームへ投影します。

時間蓄積後に3×3のフィルターを掛け、既定の2回では画素間隔1、2を使用します。計算済みの法線・線形深度を再利用して、違う面や深度境界を越えて影を混ぜにくくしています。生のマスクは保持し、照明合成へ処理後の可視率を渡します。

カメラの履歴ID、シーンrevision、影の設定が変わると全画面の履歴を破棄します。遮蔽物・太陽方向の変更では現在の可視率と履歴を画素ごとに比較し、一致しない画素を再開します。分散と蓄積回数で空間フィルターの強さも調整します。判定の制限と検証は [RTの履歴判定](RTHistory.md) を参照してください。

半精度の深度・法線履歴、最近傍の履歴参照、近傍範囲への履歴クランプを使います。薄い形状や遠い面の境界では画質調整が必要です。線形深度が65,000ワールド単位を超える場所では履歴を使わず、生の可視率を保持します。スキニング遮蔽物の姿勢変更も画素ごとに照合します。変形する受け手は既存のスキニング用モーションベクトルと深度・法線照合を使用します。

DXR OFF、非対応GPU、空のシーン、入力不足、無効な行列・光源では、古いマスクを使わず入力画像を返します。リソース作成に失敗した場合はログを記録し、RTシャドウをOFFにします。RT用材質描画の後で失敗したフレームは太陽光が遮蔽されない場合があります。次フレームから通常の材質描画へ戻ります。

## 実行コストと検証

- TLAS構築はDXR基盤と共有し、影用にもう1つのTLASは作りません。
- 1280×720の対応画素ごとに、硬い影は1本、柔らかい影は指定サンプル数の光線を飛ばします。空・未対応画素・太陽光成分がない画素では探索を省略します。
- 追加画像は太陽光＋深度のRGBA32_FLOAT、遮蔽のR32_FLOAT、合成色のRGBA16_FLOATです。初回使用時に作成し、OFF後も再有効化用に保持します。通常描画のMRT書き込みと画像帯域も増加します。
- ノイズ除去には可視率＋蓄積数＋平均＋二乗平均のRGBA16_FLOAT履歴2枚、法線＋線形深度のRGBA16_FLOAT履歴2枚、空間フィルターのR32_FLOAT画像2枚を追加します。このGPUでの割当は合計37.5MiBです。初回使用時に確保し、OFFでも再有効化用に保持します。
- 既定では時間蓄積1パス＋空間フィルター2パスを追加します。必要なモーションベクトルの描画もRendererが有効にします。硬い影・ノイズ除去OFFでは追加フィルターパスを省きます。
- 計測は光線探索・ノイズ除去・合成を別々に表示します。CPU準備、初回パイプライン作成、太陽光MRTの描画時間、モーション描画、共有BLAS/TLAS構築時間は含みません。

`DxrTests.exe` はDXR基盤の検証に加え、実際のStandard/Toon材質で影のON/OFF、太陽光だけの合成、硬い影・柔らかい影、CastShadow、配置移動、未対応の手前面、入力不足を検証します。結果は `runtime/captures/DxrTests/shadow-result.txt`、PNGは同ディレクトリです。D3D12検証レイヤーのERROR/CORRUPTIONを失敗扱いにします。

RTX 4060 Laptop GPU、1280×720、平面の受け手と遮蔽物を使う検証では、硬い影の探索約0.16ms、16サンプル・角半径0.1ラジアンの探索約1.76ms、合成約0.10msでした。マスクと合成画像の実際の割当は11.25MiB、太陽光MRTは15MiB、合計26.25MiBです。DXR基盤・ドライバー内部メモリは別です。少数フレームの動作検証値であり、実ゲームの性能保証ではありません。

同じGPUと検証シーンで、1サンプルを32フレーム蓄積した結果を64サンプルの参照画像と比較しました。半影部分の平均二乗誤差は生の1サンプル0.158957、時間蓄積0.009895、空間フィルター後0.003769で、全処理後は約97.6%減少しました。ノイズ除去区間は約1.11msでした。結果は `denoise-result.txt`、比較画像は `shadow-denoise-raw1.png` / `shadow-denoise-filtered1.png` / `shadow-denoise-reference64.png` です。

GPUテストは画質改善に加え、モーションとジッターの再投影、カメラカット、遮蔽物移動、太陽変更、シーン変更、時間蓄積OFF、ノイズ除去OFFを検証します。
