# 追加1回のRT反射

RT反射の命中先からもう1本の反射光線を飛ばし、鏡の中の鏡に映る物体を描きます。カメラに見える受け手からの最初の反射と、命中先からの追加反射を合わせて最大2回です。追加反射を連鎖して無限に追う方式ではありません。

## 設定

`DxrReflectionSettings::shouldTraceMultipleReflections` は既定falseです。ImGuiのRT Reflectionsの「Multiple reflections」、Developmentパネルの「多重反射」で有効化します。`maxReflectionBounces` は1〜2、既定2です。1は従来の反射のみ、2は追加1回です。上限・ON/OFFを変更すると時間履歴をリセットします。

RT GI・局所ライト影のパスでは追加反射を行いません。設定構造体は共有していますが、多重反射の操作はRT反射のパネルだけに表示します。

## 対象と光の重み

追加反射を飛ばすのは、反射パスのStandard材質への命中です。金属度、基本色、鏡面強度、法線マップ、粗さ／金属度マップを解決した値を使います。鏡面強度が0、最大粗さ設定を超える面、間接光の強度が0の場合は追加しません。Unlit・Toonの命中先の照明は既存の処理を使い、そこから追加反射は飛ばしません。追加反射の終端は既存の対応材質を参照できます。

粗さ0.02未満は鏡面方向、それ以外はGGX VNDFから1方向を選びます。光の重みは最初の反射と同じ、色付きフレネル×SmithのG1(L)×鏡面強度×間接光強度です。初回サンプルと反射深さからseedを作り、サンプルごとに追加の方向を変えます。子の光線からさらに複数サンプルへ枝分かれさせません。

命中先に既に含まれた環境鏡面成分を、子の命中がある場合にだけ差し引き、重み付けした子の放射輝度へ置き換えます。直接光・環境拡散光は残します。Standard IBLと従来の環境マップは、それぞれ既存の係数・Mip・近似式で差し引き量を計算します。ミスや切り抜きを通過して何もない場合は命中先の環境反射を残し、黒い面への命中はその環境反射を黒へ置き換えます。IBLの近似とGGXの厳密な同一積分を保証するものではありません。

`maxDistance` は光線区間ごとに適用します。合計2区間で最大2×maxDistanceの経路を扱えます。ReceiveShadow、太陽光遮蔽、有効な選択局所ライトの影は最後の命中先でも従来の処理を使います。法線による原点オフセットとrayBiasも各区間に適用します。

光線幅は命中距離まで広げて子へ渡し、入射角と子の粗さによる広がりを追加します。[RTテクスチャのMip選択](RTTextureMips.md) を終端のテクスチャにも適用します。最初の命中位置・距離・置き換え率は子の結果で書き換えず、既存の履歴・合成用データを保持します。

## 実行コスト

光線payloadは32から40bytesへ増やし、深さとサンプルseedを保存します。最大DXR再帰深さは2から3へ変更し、「最初の反射→追加反射→終端の影光線」を許可します。設定の反射回数は2以内に制限し、深さ2の放射輝度光線は追加反射を行いません。

描画画像、SRV、96bytesのヒットレコード、定数バッファ枠、BLAS/TLASは追加しません。既存の定数パラメーターの空き成分へ反射上限を渡します。OFFや上限1では追加TraceRayを呼びませんが、payloadとパイプライン再帰上限の拡張は共有シェーダーに残ります。ドライバーの内部スタックやレジスターへの負荷はGPU・ドライバーに依存します。

各初回サンプルにつき追加の放射輝度光線は最大1本です。最大16サンプルなら、半解像度の対応画素あたり放射輝度光線は最大16→32本です。終端の照明計算・テクスチャ参照も追加します。太陽光の影は命中ごとに最大1本、局所ライト影は選択最大8灯×最大16本で最大128本です。全ての対象・ライト条件を満たす理論上限では、各初回サンプルの探索は `(1 + 1 + 128) * 2` 本です。実際はミス、粗さ・光強度・範囲・法線方向・ライトの条件で減ります。

これは光線数の上限で、GPU時間が必ず2倍になるという意味ではありません。通常実行時の追加GPU時間は未測定です。

DXR再帰とスタックの仕様：[Microsoft DXR Functional Spec](https://microsoft.github.io/DirectX-Specs/d3d/Raytracing.html)。

## 検証

`DxrTests.exe --multiple-reflections` は画面に見える鏡から45度の鏡、その先の色付き物体へ反射する検証シーンを使います。OFF、上限1／2、最初の命中率の維持、区間ごとの距離、色付き金属フレネル、非金属フレネル、鏡面強度0、Unlit、切り抜きのミス、黒い命中、環境反射のフォールバック、終端の照明と深さ3の太陽光影、向かい合う鏡の回数制限、粗い面の単位光の上限、履歴と設定変更を確認します。既存RT反射テストも同時に実行します。

引数なしの全DXR GPU検証にも含みます。D3D12検証レイヤーのERROR/CORRUPTIONを失敗扱いにします。結果はruntime/captures/DxrTests/multiple-reflection-result.txt、PNGも同じディレクトリです。

2026-10-09、RTX 4060 Laptop GPUで多重反射と既存反射の単独検証、全DXR GPU検証が終了コード0で成功しました。Developmentビルドも成功しています。2枚の鏡を通した赤の信号は0.999512、最初の命中率は1でした。粗さ0.6の追加反射の中心31×31画素の単位光平均は0.762919で、各画素の非有限値・単位光増幅も検証しています。通常実行時の性能測定ではありません。

## 制限

追加1回の鏡面反射で、拡散GIの多重バウンスは行いません。終端は既存の環境照明を含む照明近似です。多重散乱によるエネルギー補償、二次光線の霧、透明・屈折、独自の頂点変形や材質の完全な再現は対象外です。

追加先の粗い反射には1サンプルのノイズがあり、受け手が鏡面でもその先の粗い面にはノイズが出ます。履歴・空間フィルターと深度のガイドは最初の受け手・最初の命中を基準にするため、後段の形状の出入りまで完全に検出する方式ではありません。既存のシーン変更フラグと信号照合で対応しますが、細い形状や反射対象の移動では残像やちらつきの調整が必要です。
