# モーションベクトル

`MotionVectorRenderer` は画面UV単位の「現在位置 − 前フレーム位置」を `R16G16_FLOAT` に出力します。Xは右、Yは下が正です。ピクセル単位にする場合は解像度を掛け、過去の位置を探す場合は現在UVからベクトルを引きます。初回・未描画からの復帰・カメラ切り替え・シーン切り替えではゼロ出力にします。

`Renderer` が通常の3D描画中だけ収集を有効にします。`Object3d::Draw()` と `SkinningObject3d::Draw()` が提出した三角形を収集し、色と深度の描画後に専用パスで描画します。通常描画の深度を参照し、深度には書き込みません。シーンごとの対象列挙関数は不要です。

- 通常モデルは前フレームのワールド・ビュー・射影の合成行列を保持します。
- スキニングモデルは前フレームの変形済み頂点をGPUバッファに保存し、現在・過去の位置を2本の頂点ストリームから読みます。追加の骨計算は不要です。
- 頂点変形モデルは `Object3d::SetMotionVectorShader()` で対応するVSを明示します。共通の `MotionVector/Common.hlsli` の入力・出力、b0/b1の現在・過去WVP、b2/b3の現在・過去の4成分パラメータに従います。クラゲの変形はゲーム側でシェーダーを指定します。
- 瞬間移動は対象の `ResetMotionHistory()`、カメラカットは `Camera::ResetMotionHistory()` を呼んでください。通常の毎フレームの移動ではリセットしません。

`Renderer::GetMotionVectorRenderer()` から設定、SRV、履歴リセットを利用できます。Debug構成の「Motion vectors」ウィンドウで有効化と可視化を切り替えられます。可視化は停止が黒、方向が色、移動量が明るさです。HUDの前に描画するため2Dの表示は維持されます。

DLSS Super Resolutionからこの出力を利用します。現在・過去WVPは投影ジッターを除き、b4の2成分NDCジッターを描画位置だけに適用します。透明物、粒子、空の背景、未対応の独自VSは出力対象外です。独自VSは対応するモーションVSを指定してください。標準の剛体・スキニングモデルでは `SetAlphaCutoff` によるピクセル破棄を通常描画と共有し、穴の奥のモーションを維持します。切り抜き材質はb5の材質CBVとt0/s0のテクスチャ・samplerを使う専用PSOへ切り替えます。カスタムのモーションVSと切り抜きの組み合わせは現在未対応です。詳細と負荷は [アルファ切り抜き](../Raytracing/AlphaMasks.md) を参照してください。解像度は既存描画と同じ固定の `WinApp` サイズです。

コストは対象の三角形の追加描画1パス、テクスチャ書き込み、前フレームの行列保持です。1080pの出力テクスチャは約7.9 MiB。スキニングは対象ごとに頂点バッファ1個分のGPUメモリと、描画後のGPUコピーが加わります。無効時は対象の描画と頂点コピーを行いませんが、出力テクスチャの確保とゼロクリアは維持します。

描画テストではGPUから値を読み戻し、移動の方向・UV単位の値・停止・リセット・実際のGPUスキニングによるポーズ変化を確認します。

RTの履歴判定用に、同じモーション描画から前フレームの幾何法線・ビュー深度・物体IDをRGBA32_FLOATの画像2枚へ出力します。既存のR16G16_FLOAT出力とスキニング頂点コピーは維持します。モーションルートのb6は描画ごとの再投影CBVです。GetReprojectionSrv()・GetPreviousReprojectionSrv()をRTの入力へ渡します。1280×720の追加実割当はRTX 4060 Laptop GPUで30MiBでした。処理・検証・独自VSや法線マップの制限は [動く受け手の履歴](../Raytracing/RTReceiverMotion.md) を参照してください。
