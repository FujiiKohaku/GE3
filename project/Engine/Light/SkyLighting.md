# 天空・大気と照明の統合

`LightManager::SetSkyLighting(true, 1.0f)` で共通の解析的な天空光を有効にする。初期値は OFF。開発パネルにも切り替えと倍率を公開する。

## 接続

- `Atmosphere/SkyLighting.hlsli` は線形 HDR の天空放射輝度を評価する。既存の単一散乱近似 `AtmosphereRadiance`、太陽方向・RGB・強さ、大気散乱強度と異方性、地面色を利用する。
- `SkyBox` の表示、Standard の拡散環境光と粗さ付き鏡面環境光、通常・スキニング描画、RT ヒットの材質評価が同じモデルを使う。
- 太陽円盤は表示だけに追加する。環境光への円盤の積分は行わず、直接光との重複を避ける。
- 拡散環境光は既存の余弦分布6方向を使う。鏡面環境光は中央と周囲4方向の重み付き平均で粗さを近似する。
- RT の複数反射で置き換える環境光にも同じ評価を使う。RT ミスは既存の環境光フォールバックを維持する。
- スクリーン大気遠近法も同じ散乱モデルと天空倍率を利用する。大気密度は距離による透過率を制御する。
- 太陽・天空倍率・大気設定の変更は RT の反射/GI の履歴を破棄する。モード OFF はキューブマップ方式に戻る。

## 使用例

```cpp
LightManager* lights = LightManager::GetInstance();
lights->SetSkyLighting(true, 1.0f);
lights->SetEnvironmentLighting(0.4f, 0.6f);
lights->SetAtmosphere(true, 0.00035f, 1.0f, 0.65f);
lights->SetDirectional({1, 1, 1, 1}, {0, -1, 0}, 4.0f);
```

`SetSkyLighting` の倍率は有限な 0〜2。環境光の拡散・反射倍率の変更は天空モードを維持する。シーンで ON にするときは既存の環境光倍率と露出を調整する。これはライティング機構の追加であり、既存シーンの見た目を自動で変更するものではない。

## コストと限界

追加レイ数・描画パス数・画像メモリはゼロ。`environmentSettings.z/w` の未使用成分を再利用し、定数バッファのサイズとバインドも維持する。天空表示は1方向、Standard の環境光は拡散6方向と鏡面最大5方向、RT ヒットごとにも同様の解析計算を行う。GPU 時間は解像度、可視面積、RT ヒット数で変わる。履歴判定用の CPU データをレンダラーごとに8バイト追加する。

これは既存散乱式を共有した近似で、物理的大気の LUT、多重散乱、雲の照明、地面の反射積分、GGX の厳密な天空プリフィルタは未実装。Toon の半球環境光など専用の美術表現は従来通り。大気遠近法と立体霧を同時に強くすると二つの媒質の消散が重なるため、シーン設定で濃度を合わせる必要がある。

## 検証

`DxrTests.exe --sky-lighting` は昼・夕方・夜の通常描画/RT の色一致、ゼロ倍率、設定の範囲検証、キューブマップ復帰、安定時の RT 履歴再利用と大気設定変更時の履歴破棄、実際の SkyBox の HDR 出力を検証する。結果と画像は `runtime/captures/DxrTests/sky-lighting-result.txt` などに保存する。

2026-10-10 の単独検証（RTX 4060 Laptop GPU、Debug、1280×720）では、天空表示単体0.0512 ms。これは空を描くパスの全時間で、環境光・RT ヒットの追加演算時間は含めず、既存方式に対する差分でもない。昼の通常描画 RGB は (0.3125, 0.441895, 0.543457)、RT は (0.312012, 0.441162, 0.54248)。太陽強度4の表示空は RGB (1.13184, 1.90137, 2.37695) で HDR が保たれることを確認した。

Development ビルドと DXR 全件検証は成功。全件検証中の天空表示の測定は約0.31 msだったため、単独実行値を固定の性能保証には使わない。既存 `ShadowMapTests` 全件の半球光画像比較の失敗は別件として未解決で、今回の回帰確認には既存の `--volumetric` 重点実行を使用する（大気遠近法・環境光・立体霧などを含む）。

`ShadowMapTests.exe --volumetric` も終了コード0。大気遠近法の画像差分436,058画素、環境光435,491画素を確認し、既存の霧・影・ポスト処理の検証と D3D12 検証を通過した。
