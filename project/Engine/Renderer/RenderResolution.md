# 3D描画解像度と表示解像度

表示・粒子合成・HUD・UI・Bloom・露出・最終トーンマッピングは1280×720。3Dカラー、深度、法線、間接光、材質、RT用キャプチャ、モーション、前深度/物体ID、SSR/SSGIとRTの出力、霧の画像を指定した3D解像度へ合わせる。影マップと加速構造の品質は解像度倍率に連動しない。DXRの診断表示用出力も従来の表示解像度。

## 操作

既定は低解像度OFF。Debugの「Anti-aliasing comparison」の `Low resolution rendering`、960×540、640×360ボタンで操作する。Developmentの「アンチエイリアス比較」にも同じ操作と実際の3D描画幅・高さがある。

| 低解像度 | TAA | 結果 |
|---|---|---|
| OFF | OFF | 1280×720で描画。必要なら既存DLAA/FXAAを選択 |
| OFF | ON | 1280×720のネイティブTAA |
| ON | OFF | 960×540または640×360で描画し、双線形補間で1280×720へ拡大 |
| ON | ON | 低解像度でジッター付き描画、モーションと履歴を使って1280×720へ復元 |

低解像度ON中はネイティブ専用DLAAの評価を停止し、入力サイズが異なる画像をNGXへ渡さない。TAAはAIを使わない。GPU時間に応じた自動倍率変更は未実装で、手動の解像度選択。

`Renderer::SetLowResolutionRendering(bool isEnabled, uint32_t width = 960, uint32_t height = 540)` は設定だけを変更し、描画開始時に前フレームのフェンス完了後、描画先を更新する。入力は偶数寸法、320×180以上、1280×720以下、表示と同じ縦横比。OFFは選択した低解像度に関係なく1280×720へ戻る。実際の適用寸法は `GetSceneRenderWidth/Height`。AAの設定は `SetTemporalAntiAliasing` / `SetAntiAliasing`。

## 描画順と資源

1. 3Dカラー・深度・キャプチャ・モーションを入力解像度で描画。
2. RTの太陽/ローカルシャドウ、GI、反射、スクリーン照明、霧を入力解像度に対応させて合成。
3. 汎用TAAまたは空間補間で表示用のHDRカラーへ復元。
4. 低解像度深度を最近傍で表示用深度に復元。入力のジッター分を補正し、前景と背景の深度を混ぜない。
5. 粒子を表示解像度のカラー・深度に描画し、後段エフェクト・露出・Bloom・トーンマッピング・HUD・UIを処理。

`SceneRenderResolution` は既存の単一Renderer/DirectXCommonに合わせた共有の3D寸法。ウィンドウ・スワップチェーンの寸法は変更しない。寸法変更でTAA、モーション、SSR、SSGI、RT、霧、露出の履歴を破棄する。RT資源は次の評価で作り直す。

## 実行コストと制約

960×540は元の56.25%、640×360は25%の画素数。ラスタのピクセル処理と画面空間・RTの画素処理を削減できる。物体数・頂点数・影マップ・BLAS/TLAS・CPU更新・表示解像度の後段処理は同じなので、フレーム時間全体が同じ比率で減るとは限らない。

低解像度時に表示解像度の深度復元を1パス追加する。TAAは従来の表示解像度の30MiB履歴を使う。低解像度用ポストカラー2枚と表示用粒子深度が別途必要。再有効化用に低解像度用ポスト画像と粒子深度を保持するため、OFFが全追加メモリの解放を意味するわけではない。倍率切り替え時は再確保による一時的な負荷と履歴の再収束がある。

復元では新しい細部を完全に再現できず、細線・透明物・新たに見える面ではにじみや揺れが残る場合がある。細部を優先するときは低解像度OFFを使う。粒子深度は低解像度由来なので、輪郭の遮蔽精度は元の入力画素数に制約される。追加の3D深度プリパスは行わない。SSRの階層深度領域は従来の2048×1024を維持する。

## 検証

`ShadowMapTests.exe --taa` でタイトル/ステージ03、ネイティブ/960×540/640×360、TAAの独立切り替え、履歴破棄、ネイティブ粒子カラー/深度、反復切り替えの記述子数、D3D12 ERROR/CORRUPTIONを確認する。対応GPUではRT太陽影、ノイズ除去、反射、GI、霧の寸法も確認する。

実測結果は `runtime/captures/ShadowMapTests/taa-integration-result.txt`。Debugの短い実行の最終フレーム値であり、平均ベンチマークや性能保証ではない。画像は `resolution-75-taa.png` / `resolution-50-taa.png`。

## 品質の一括選択

RTと霧の品質は [RenderQuality.md](RenderQuality.md) のプリセットで変更する。低解像度のON/OFFは独立して保持し、推奨解像度の適用は別操作。
