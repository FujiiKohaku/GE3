# MyEngine - 3Dゲームエンジン ＆ テストアプリケーション

自作の DirectX12 3Dゲームエンジン「MyEngine」と、それを用いた3Dアクションシューティングのテスト用アプリケーションです。

---

## 🚀 主な機能と実装詳細

本プロジェクトでは、3Dグラフィックスとアニメーションに関する高度な機能が実装されています。

### 1. キャラクターアニメーション & GPUスキニング
* **GPUスキニング (Compute Shader)**: スキニング処理を GPU（[Skinning.CS.hlsl](file:///c:/project/MyEngine/project/resources/Shaders/Object3D/Skinning.CS.hlsl)）で実行。計算結果バッファをそのまま頂点バッファとして使い回すことで、CPU-GPU間の転送ボトルネックを排除し、高速な描画を実現しています。
* **アニメーションブレンド**: 2つのアニメーション（待機・走り・攻撃など）を球面線形補間（SLERP）を用いて滑らかに補間・ブレンドします。

### 2. Foot IK (インバースキネマティクス) ＆ 膝の補正
* **地形接地補正 (Foot IK)**: キャラクターの足元からレイキャストを行い、傾斜地や段差の高さ・法線に合わせて足首の位置と角度をリアルタイムで補正します。
* **膝のポール補正 (ポール方向制御)**: 足の位置変化に伴い、膝の曲がる方向（ポール）をベクトルの外積・内積計算から自動的に計算・補正し、関節が不自然な方向へ曲がらないようにします。

### 3. GPUパーティクルエフェクト
* **ダイナミックな演出**: 「風のそよぎ」「ブラックホールによる吸引効果」「多段爆発（二重破裂）」などの高度な粒子シミュレーションを GPU 側で実行しています。

### 4. 34種類のポストエフェクト
* 画面全体の印象を劇的に変えるポストプロセッシングフィルタを計34種類搭載。
* **主なエフェクト**: 被写界深度 (DoF), 放射状ブラー (Radial Blur), モーションブラー, ブルーム, レンズフレア, 衝撃波 (Shockwave), ガラスのヒビ割れ, 熱気 (Heat Haze), ブラックホール歪みなど。
* ゲームプレイ中にマウスホイールを用いて瞬時に切り替え・確認が可能です。

### 5. 骨格デバッグ表示 (Skeletal Debugger) 【新規実装】
3Dモデルのボーン構造を視覚的にデバッグ・評価するための高度なオーバーレイ機能を実装しました。
* **ボーン接続線**: ジョイント間を細い線で結び、姿勢変化を可視化します。
* **ジョイント・ローカル軸表示**: 各関節位置に、ローカル座標系の **X軸（赤）**, **Y軸（緑）**, **Z軸（青）** の短い矢印（長さ 0.25）を描画します。
* **ボーン名テキストオーバーレイ**: 各関節の3Dワールド座標をカメラのビュー・プロジェクション行列を用いて2Dスクリーン座標に変換し、エンジン内蔵の 2D Text 表示機能を使用してボーン名（`pelvis`, `hand.L` など）をキャラに追従させて画面上に描画します。

## 🎮 テストシーン (TestScene1) の操作方法

ゲームの起動後、タイトル画面から `TestScene1` に遷移することで、上記の機能をすべて体験できます。

| 操作キー / マウス | アクション |
| :--- | :--- |
| **`W` `A` `S` `D`** | プレイヤーキャラクターのレール移動 |
| **`LSHIFT`** | ブースト加速（加速中はスピードが上昇し、エフェクトが変化） |
| **`A` または `D` のダブルタップ** | ローリング回避（キャラクターが横に1回転して素早く移動） |
| **`SPACE` または `左クリック` (長押し)** | 弾の自動連射（ミニガンモードでは熱ゲージが蓄積し超高速連射） |
| **`1` `2` `3` キー** | 武器の切り替え（`1`: 通常弾, `2`: ミサイル, `3`: ミニガン） |
| **マウスホイール** | ポストエフェクト (34種類) のリアルタイム切り替え |
| **`ESC` キー** | タイトルシーンに戻る |
