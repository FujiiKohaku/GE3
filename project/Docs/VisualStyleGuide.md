# アニメ調ビジュアル基準

Stage03を本作の完成見本とする。新しいステージ、モデル、エフェクト、HUDは、まずStage03と並べて違和感がないことを確認する。

## 機能色

| 意味 | 基準色 | 用途 |
|---|---|---|
| プレイヤー行動 | シアン `#53D8E8` | 弾、命中、ミサイル、通常噴射、ブースト |
| 敵の危険 | 朱赤 `#FF5A3D` | 敵弾、被弾、警告、ボスHP |
| 回復 | ミント `#79E6B3` | 回復アイテム、回復パーティクル |
| UI補助 | 真鍮 `#B68A4A` | 中間警告、補助ゲージ、装飾 |
| UI罫線 | アイボリー `#E8DEBF` | HUD外枠と文字の補助 |

機能色は演出の種類ではなく意味で選ぶ。敵弾を氷属性だから青にする、といった例外は作らない。攻撃の種類は形、軌道、大きさ、タイミングで区別する。

## 通常ポストエフェクト

通常画面は `DepthOutline + Fog` を基礎構成とする。ブースト中だけ `RadialBlur + FocusLine + Bloom` を追加する。

被弾、ペイント、水滴、ジャスト回避、ボス撃破など、ゲーム状態を伝える短時間の演出は追加してよい。ランダムノイズ、色収差、常時の熱気歪み、ガラス割れ、走査線は通常構成へ入れない。

## HUD

武器、プレイヤーHP、ボスHPは共通フレームを使う。共通フレームは濃紺の半透明パネル、アイボリーの3px罫線、機能色のコーナーアクセントで構成する。

回復色のミントはHPゲージの通常色に使わない。プレイヤーHPは通常シアン、中残量は真鍮、危険時は朱赤とする。

## パーティクル

細粒を大量に散らさず、少数の大きな図形で動きと意味を伝える。基本部品は、太いトゲ、ひし形、リング、テーパー状の帯、煙塊の5種類とする。

- 単発エフェクトは原則12形状以内、継続エフェクトは24形状以内とする。
- 白い芯、機能色の本体、濃色の縁という3段階で構成する。
- 色とアルファは滑らかにぼかしすぎず、2～3段階へ量子化する。
- 強いランダムノイズを避け、形、回転、拡大縮小で勢いを作る。
- 発光は中心と開始フレームに限定し、全体を常時発光させない。

## Stage03 完成判定

次の条件をすべて満たした状態を、他ステージへ展開できる完成基準とする。

- 氷床と氷オブジェクトが明・中・暗の3段階セル陰影で読める。
- 主光源は青白く、暗部が黒潰れせず、輪郭線が背景から分離して見える。
- プレイヤー弾はシアン、敵弾は朱赤、回復はミントとして一目で判別できる。
- 通常移動中に画面全体の色調を壊すポストエフェクトが発生しない。
- 武器、HP、ボスHPの外枠・余白・罫線・アクセント規則が共通である。
- ブースト、被弾、回復、ボス戦の各状態が、色と動きの両方で判別できる。
- Release構成で起動し、Stage03の開始からボス戦まで表示崩れやクラッシュがない。
