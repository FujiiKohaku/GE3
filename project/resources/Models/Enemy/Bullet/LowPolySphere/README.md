# 弾用の低ポリゴン球体

- `lowPolySphere.obj`：原点中心・半径1、42頂点、80三角形。
- 正二十面体を1段階細分化し、全頂点を球面上へ投影。頂点法線は中心から外向きで、滑らかな陰影を付けられる。
- 拡大すると輪郭に角が見える。小さな弾としての使用を想定し、形状の丸さと面数を両立したもの。
- `lowPolySphere.mtl` は既存の `resources/Textures/white.png` を参照。色はゲーム側で設定できる。
- 既存の Debug/Sphere/sphere.obj の1,024面に対して、面数は約92％少ない。描画時間の削減率を保証する値ではない。
- OBJ の再読み込み、閉じたメッシュ、外向きの面、半径、テクスチャ参照先を確認済み。
- 現在の敵弾はライティング無効のため、滑らかな法線による陰影はそのままでは表示されない。輪郭の丸さはこのメッシュ形状による。
- ゲームプレイの共有敵弾モデルとして適用済み。ModelManager の読み込みパスは `Enemy/Bullet/LowPolySphere/lowPolySphere.obj`。
- 色は既存の EnemyBullet の朱赤（RGBA: 1.0, 0.353, 0.239, 1.0）を使用。白テクスチャにゲーム側の色を掛けるため、MTL の拡散色は白のままとする。
- 元の箱モデルは各軸±0.5、この球体は半径1。差し替え時は表示サイズを確認する。
