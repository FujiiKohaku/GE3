# 浮遊遺跡の回転防衛装置

合成した完成イメージを参考に、砂岩の装甲、古代の金属フレーム、青緑の結晶、赤橙の危険な縁を持つ回転装置を作成。

- `ruins_rotor_hub_bar.obj` / `.mtl`：中央の軸・結晶と対向する腕2本。1,676三角形・4マテリアル。
- `ruins_rotor_bar.obj` / `.mtl`：残りの対向する腕2本。1,320三角形・3マテリアル。
- `ruins_rotor.blend`：編集・プレビュー用。2本のモデルを直交させて表示。
- `previews/ruins_rotor.png`：Blenderによる参考画像。ゲーム画面のスクリーンショットではない。
- `textures/`：64×64の4枚の専用画像。OBJから相対パスで参照。

腕の全長はネイティブ単位で46。STAGE1の進行距離2350と4620の2か所（計4オブジェクト）に配置済み。後半は全長48に合わせた等方スケール。回転軸・初期角度・速度0.9/-1.05・既存の腕の箱判定・ダメージ2を維持し、各装置の中央にだけ直径7.2相当のBOX判定を追加している。2モデルの腕は中央で途切れ、中央の軸と結晶は片方だけが持つ。

専用PSは `resources/Shaders/Object3D/RuinsRotor/Render.PS.hlsl`。通常の石・金属のライティングに加え、危険な縁と結晶だけをHDR発光として出力する。OBJのMTLに書かれた発光ノードには依存しない。UVのU座標に材質の識別情報を持たせているため、編集時に維持する：石0〜1、金属2〜3、危険な縁4〜5、結晶6〜7。画像サンプラーのリピートで通常の色を参照する。

生成・設置元：`project/Tools/ModelGeneration/CreateRuinsRotor.py`。Blender 4.4で実行。再実行可能で、他のシーンオブジェクト・元の回転設定・腕の判定が変わらないことを検査する。光の軌跡はモデルには含めていない。

2か所で合計5,992三角形。腕の回転は既存の処理を利用し、中央判定を2箱追加。モデルと画像は共有するが、元の箱より描画する三角形とマテリアルが増える。ゲーム内の表示・回転・ブルームは実行環境での確認が必要。
