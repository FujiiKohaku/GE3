# STAGE1 山島の配置

ユーザー提供の `rock_mountain_ruins.obj` を序盤の進行距離440へ配置。既存の距離240の `Gate01_FloatingRuins_ground` と `Gate01_FloatingRuins_masonry` の2オブジェクトを `Stage01_MountainRuins` に置換した。初期画角で山島が大きく見え、水路橋も見える距離へ調整した。

- エンジン座標の位置：X=0、Y=-30、Z=440。
- スケール：X=14、Y=9.5、Z=9.5。横幅約336、高さ154、奥行き105。
- 向き：エンジンY軸で180度回転。水路橋と塔が見える面から接近する。
- 下部の開口はメッシュが奥まで貫通している。
- 当たり判定：岩の正面形状を縦の32箱で近似。開口部を塞ぐ単一の箱は使用しない。
- 通行検査：X=-16〜16、Y=-5〜5、Z=370〜520の1,140点。判定半径1.5の余裕で全箱から離れていることを検査。元メッシュからの距離は非等方スケールの最小倍率を使い、保守的な下限でも約10.82ある。
- 9,158三角形、17マテリアル。通常描画は最大17回程度に加え、影の描画が発生する。箱は世界座標のオフセット・寸法で保存しており、モデルの拡大率を二重には適用しない。

MTLの色 `Kd` から16×16の単色PNGを17枚作り、`map_Kd` を追記した。元のOBJの頂点・形状は変更していない。エンジンが色を既定のキューブテクスチャで上書きしないための取り込み用データ。

`previews/stage01_mountain_ruins.png` は実際のモデル・配置・初期カメラ相当の画角を使うBlenderプレビュー。ゲーム画面のキャプチャではない。`stage01_mountain_ruins_preview.blend` はその編集用データ。滝はこのモデルには含まれず、今回は追加していない。

生成・設置は `project/Tools/ModelGeneration/PlaceMountainRuins.py` をBlenderで実行する。再実行可能で、対象以外のステージオブジェクトを変更していないことを検査する。詳細な検査値は `placement_info.json`。

ゲーム実行での見た目・通過操作は未確認。

## 山島専用の表面シェーダー

`resources/Shaders/Object3D/MountainRuins/Render.PS.hlsl` をこのモデルだけに適用。元の17色の単色テクスチャから草・岩・石灰岩を識別し、暖かい土褐色の岩、苔色の草、風化した砂岩色の遺跡へ再配色する。UV・形状・当たり判定は変更しない。

二段のワールド座標ノイズで色むら・粒子状の凹凸・地層・薄い亀裂を作り、画面微分で細部の凹凸を法線へ反映。遠距離では細部を弱める。岩は海面Y=-30付近だけ暗く、滑らかにして濡れた質感にする。草・遺跡・乾いた岩は異なる粗さと鏡面反射強度を使い、山島の陰影は段階的なトゥーンではなく滑らかな拡散反射と既存の鏡面反射を使用する。

追加の描画パス・メッシュ・テクスチャ参照はなし。元の色テクスチャ参照に加え、PS内のノイズと微分計算が増える。上記Blenderプレビューは配置・形状確認用で、このゲーム内PSの質感は再現していない。
