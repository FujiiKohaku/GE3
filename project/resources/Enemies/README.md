# 通常敵のレベル設定

`normal-enemy-levels.json` に通常敵のレベル1〜3の性能を定義する。

| レベル | HP | 射撃間隔（フレーム） | 弾速（フレーム当たり） | 放射弾 |
|---|---:|---:|---:|---|
| 1 | 1 | 180 | 0.36 | 無効 |
| 2 | 4 | 120 | 0.48 | 有効 |
| 3 | 8 | 90 | 0.60 | 有効 |

ステージ配置JSONの `EnemySpawn` / `file_name: "NormalEnemy"` に `"level": 1` のように追加する。位置・回転・巡回経路は従来どおり指定する。未指定はレベル2。既存配置にはレベルを追加していないため、従来の性能を維持する。

JSONの公開設定名は `hp`、`fireIntervalFrames`、`bulletSpeedPerFrame`、`isRadialShotEnabled`。HP・弾速は有限の正数、射撃間隔は正の32bit整数、放射弾はboolを指定する。不正な性能定義はそのレベル全体を従来の性能（HP4・120フレーム・弾速0.48・放射弾有効）へ戻し、警告を記録する。不正な配置レベルは2へ戻す。

設定はステージの初回読み込みとレベル再読み込み時に読み直す。フレームごとのJSON読み込みは行わない。適用箇所は通常敵を生成する分岐だけで、通常敵を継承する装甲敵、移動敵、群れ、ペイント敵、ボスには適用しない。

通常敵の読み込みを利用している既存の未知 `file_name` のフォールバックも同じレベル設定を利用する。新しい種類の敵を作成する仕組みではない。

検証：`project/Tests/NormalEnemyLevelTests.cpp`。
