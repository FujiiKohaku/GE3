# カメラ専用レール

`CameraRail` は `Rail` を継承し、プレイヤーレールからの相対経路を持ちます。
ステージJSONのトップレベルに `camera_rail` を追加すると使用できます。
未指定・空配列なら、通常のレールと常に重なり、従来の距離感を維持します。
既存ステージには演出を追加していません。

```json
"camera_rail": {
  "points": [
    { "distance": 800,  "offset": [0, 0, 0] },
    { "distance": 950,  "offset": [25, 12, 0] },
    { "distance": 1150, "offset": [25, 12, 0] },
    { "distance": 1300, "offset": [0, 0, 0] }
  ]
}
```

- `distance`: プレイヤーレールの始点からの距離。非負・昇順・重複不可。
- `offset`: 元のレールに対する右・上・前方向のずれ。通常の後方距離と上方オフセットは、この上に従来どおり加算します。
- 点は4個以上。最初と最後のoffsetはゼロにします。その範囲外ではずれがゼロになります。
- Catmull-Rom曲線を使用するため、中間で指定値を少し超えることがあります。
- 各点間の進行をsmoothstepで補間し、対応点では移動を緩めます。
- プレイヤーの進行距離を直接使うため、加減速・停止・進行位置の変更にも同期します。
- 視線は従来どおりプレイヤーレールの前方を向きます。独立した注視点の設定は未対応です。
- レールの分岐・自動延長には元レール基準で追従します。
- 全方位モード、既存のカメラポイント演出、デバッグカメラは従来の処理を優先します。
- 描画カメラと照準用カメラの両方に経路のずれを適用します。描画側の既存の遅延追従は維持します。

メインカメラの所有権や追従先の切り替えは行いません。
複数の演出を1本にまとめる場合、演出間にゼロの制御点を置いてください。ゼロの点同士の区間では、曲線の影響を受けず元のレールに重なります。
